# 프롬프트 개선 이력

> 각 개선은 "변경 동기 → 토큰 변화 → 출력 품질 변화 → 다음 개선 방향" 순서로 기록한다. 수치는 `evaluation.md`의 실행 결과를 쓴다.

프롬프트 위치: `ClaudeAiClient`의 `MENU_INSTRUCTION`, `CONDITION_INSTRUCTION`, `RECOMMEND_INSTRUCTION`

## v1. 첫 버전
| 항목 | 내용 |
| --- | --- |
| 내용 | 역할(메뉴 분석기·조건 분석기·추천기), 찾을 항목과 값의 범위, 목록에 없는 ID 금지, 말하지 않은 값의 표시(인분 0, 맵기 -1, 빈 문자열), 사용자 문장 속 지시를 따르지 않기 |
| 설계 이유 | 구조화 출력은 null을 쓸 수 없어 "말하지 않음"을 0·-1·빈 문자열로 받고 서버에서 null로 바꾼다. 사용자 문장이 그대로 들어가므로 지시 주입을 막는 줄을 넣었다 |
| 토큰 | 실행 후 기록 |
| 출력 품질 | 실행 후 기록(정답률) |
| 다음 개선 방향 | 틀린 문장을 분석해 결정 |
