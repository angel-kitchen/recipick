# AI 모델·파라미터 선택

> 현재 설정과 그 근거. 모델 비교 결과(`evaluation.md`)가 나오면 4절을 채우고 최종 선택을 확정한다.

## 1. 현재 설정
| 항목 | 값 | 위치 |
| --- | --- | --- |
| 클라이언트 | `ai.client=fake`(기본), 키가 있는 환경만 `claude` | `application.yml` |
| 모델 | `claude-opus-5-5` | `ClaudeProperties.model` |
| effort | `LOW` | `ClaudeAiClient.withLowEffort` |
| 최대 토큰 | 4096 | `ClaudeProperties.maxTokens` |
| 타임아웃 | 15초 | `ClaudeProperties.timeout` |
| 재시도 | 2회(SDK가 429·5xx·연결 오류에만 재시도) | `ClaudeProperties.maxRetries` |
| 응답 형식 | 구조화 출력(출력 레코드로 JSON 스키마 지정) | `outputConfig(Class)` |
| 프롬프트 캐시 | 자연어 장보기의 레시피 목록에만 적용 | `extractMenus` |
| temperature | 보내지 않음 | - |

## 2. 파라미터 근거
- **effort `LOW`:** 하는 일이 문장에서 메뉴·조건을 찾고 목록에서 고르는 것이라 깊은 추론이 필요 없다. effort를 낮추면 생각에 쓰는 토큰과 응답 시간이 줄어든다. Opus 5.5는 생각을 끌 수 없어 effort가 유일한 조절 수단이다.
- **최대 토큰 4096:** 생각과 응답이 같은 한도를 나눠 쓴다. 응답 JSON은 수백 토큰이지만 한도가 너무 작으면 생각에서 다 써 응답이 잘린다. 잘리면(`max_tokens`) 응답 오류로 보고 `FALLBACK`으로 대체한다.
- **타임아웃 15초·재시도 2회:** 사용자가 기다리는 요청이라 오래 매달지 않는다. 실패하면 오류가 아니라 `FALLBACK`(직접 고르기 안내)으로 응답한다.
- **구조화 출력:** 응답 형태를 스키마로 강제해 JSON 파싱 실패를 없앤다. 값이 맞는지(레시피 ID·인분·조건 범위)는 서버가 다시 검증한다.
- **temperature 미지정:** 구조화 출력과 서버 검증으로 결과를 고정하므로 따로 정하지 않는다. 최신 Haiku는 기본값이 아닌 샘플링 값을 보내면 400을 돌려주므로, 모델을 바꿔도 같은 요청이 통하도록 보내지 않는다.
- **캐시:** 레시피 목록은 요청마다 같아 캐시 효과가 크다. 조건 추천의 후보 목록은 조건마다 달라 캐시를 걸면 저장 비용만 더 든다.
