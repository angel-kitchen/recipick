## 1차

### 일반 회원

- **회원가입·로그인** (담당: 채빈)
    - 이메일 기반 일반 회원 가입·로그인
    - 가입 시 이름·휴대전화 입력, 이메일·휴대전화 중복 불가
    - 서비스 이용약관·개인정보 수집 동의 필수, 동의 일시 저장
    - 로그인 3회 연속 실패 시 10분 잠금
    - 액세스 토큰 30분, 리프레시 토큰 14일(HttpOnly 쿠키, Redis 저장), 로그아웃 시 폐기
    - 관리자는 별도 로그인
    - 본인의 장바구니·주문·결제·포인트 정보만 접근
- **이용 가능 지역 판정** (담당: 채빈)
    - 현재 배송지의 법정동이 서비스 지역이면 그 지역의 마트를 이용 마트로 지정하고, 아니면 이용 마트 없음
    - 서비스 범위는 법정동 단위(지역당 마트 1곳)로 제한하며, 반경(2km) 기준은 구현 완료 후 도입
    - 위치 이용 동의 후 현재 위치로 주소를 설정하거나, 위치 거부·실패 시 주소를 직접 입력
    - 가입 전에 위치 동의와 주소 설정(핀 확정, 상세 주소 입력)을 먼저 받고, 서비스 가능 여부를 비로그인으로 확인한 뒤 가입·로그인 이후 배송지로 저장(위치 우선 가입 흐름)
    - 서비스 가능 지역 확인은 로그인 없이 호출할 수 있으며, 법정동 코드를 받아 가능 여부와 마트 이름만 응답하고 아무것도 저장하지 않음
    - 범위 밖이면 이용 불가 안내
    - 현재 위치 자체는 저장하지 않고 위치 동의 일시와 확정한 배송지, 이용 마트만 저장
    - 위치 이용에 처음 동의한 시각을 기록하며, 이후 배송지를 추가해도 기존 동의 시각을 덮어쓰지 않음
- **배송지 관리** (담당: 채빈)
    - 회원당 배송지를 여러 개 저장·수정·삭제하고, 이 중 1개를 현재 배송지로 선택(최대 5개)
    - 배송지는 명칭(선택)·주소·상세 주소(필수)·법정동 코드를 저장(위·경도는 저장하지 않음)
    - 본인 배송지만 조회하며, 현재 배송지를 먼저 표시하고 나머지는 최근 등록순으로 표시
    - 저장된 배송지가 없으면 빈 목록으로 표시
    - 배송지별로 해당 주소를 선택했을 때 서비스 이용이 가능한지 표시. 현재 이용 마트와 다른 지역도 운영 중인 마트가 있으면 이용 가능으로 안내
    - 첫 배송지는 자동으로 현재 배송지가 되며, 현재 배송지는 삭제할 수 없음
    - 현재 배송지를 삭제하려면 다른 배송지를 먼저 선택해야 하며, 삭제 후 나머지 배송지·현재 배송지·이용 마트는 유지
    - 새 배송지를 현재 배송지로 선택하지 않고 추가하면 기존 현재 배송지와 이용 마트를 유지
    - 배송지는 보낸 항목만 수정하며, 주소·상세 주소·법정동 코드는 함께 변경하고 명칭은 삭제 가능
    - 현재 배송지를 수정하면 이용 마트를 다시 판정하고, 다른 배송지를 수정하면 현재 배송지와 이용 마트는 유지
    - 이미 현재 배송지인 주소를 다시 선택해도 마트 운영 상태를 다시 판정하여 이용 마트를 갱신
    - 현재 배송지가 이용 마트를 결정하고, 현재 배송지를 바꾸면 이용 마트를 다시 판정(마트가 바뀌면 이전 마트 상품은 장바구니에서 구매 불가로 표시)
    - 동시에 배송지를 등록해도 최대 5개를 넘지 않으며, 처음 등록하는 배송지의 자동 선택은 한 건만 적용
    - 배송지 등록에 실패하면 기존 배송지 선택·이용 마트·위치 동의 기록은 변경하지 않음
    - 핀 위치가 입력한 주소와 다르면 경고 후 핀 기준으로 주소를 갱신하고 상세 주소를 다시 입력
    - 서비스 지역 밖 주소도 저장할 수 있고, 현재 배송지로 선택하면 이용 마트 없이 이용 불가 안내
    - 배송지 목록을 조회하는 것만으로 현재 배송지나 이용 마트를 변경하지 않음
    - 수령인 이름·연락처는 배송지에 저장하지 않고 주문마다 입력(기본값은 회원 이름·연락처)
- **마이페이지** (담당: 채빈 화면 구성, 각 도메인 조회 제공)
    - 내 정보(이메일·이름·휴대전화(원문)·이용 마트·현재 배송지·멤버십 유형·만료일·무료체험 가능 여부)
    - 지정된 마트가 운영 중지여도 마트 정보는 표시하고, 현재 배송지의 이용 가능 여부는 별도로 안내
    - 현재 배송지 지역의 운영 마트와 지정 마트가 같을 때만 이용 가능으로 표시하며, 불일치하거나 지정 마트가 없으면 이용 불가 안내
    - 정보 조회만으로 저장된 배송지나 이용 마트를 변경하지 않음
    - 멤버십은 이용 기간과 즉시 종료 여부를 기준으로 표시하며, 자동갱신을 해지 예약해도 남은 이용 기간에는 혜택 유지
    - 무료체험 가능 여부는 관리자 지급을 포함한 모든 멤버십 이용 이력이 없는 회원에게만 가능으로 표시
    - 주문 내역, 결제 내역, 취소·환불 내역을 한 화면에서 제공
- **멤버십 기능 제한** (담당: 채빈)
    - 자동 장바구니·AI 요청 시 멤버십 안내
    - 상품 검색·직접 장바구니·주문·결제는 이용 가능

### 유료 회원

> 유료 회원은 일반 회원 기능을 모두 포함하며, 체험 회원도 대상입니다. 자동 구성은 모두 **이용 마트의 상품·판매 단위·가격·재고**를 기준으로 계산합니다.
>

- **멤버십 활성 검증** (담당: 채빈)
    - 요청 시 서버에서 활성 여부와 유형(일반·체험·유료) 판정
    - 내 멤버십에서 현재 이용권의 유형·발급 경로·이용 기간·자동갱신·해지 예약과 무료체험 가능 여부를 확인
    - 시작 시각부터 종료 직전까지 혜택을 적용하며, 해지 예약은 남은 기간의 혜택을 유지하고 즉시 종료된 이용권은 제외
    - 주문 등 특정 시점의 혜택 유형은 당시 이용 기간과 실제 종료 시각을 기준으로 판정

### 관리자

- **관리자 로그인** (담당: 채빈)
    - 관리자 전용 로그인
    - 관리자 계정은 초기 데이터로만 생성(가입 불가)
    - 관리자 역할과 소속 마트 구분
    - 비활성 계정은 로그인 거부
    - 관리자 API는 관리자 토큰만 허용
    - 로그인 3회 연속 실패 시 10분 잠금(회원과 동일)
- **멤버십 관리** (담당: 채빈)
    - 관리자 이용권 지급은 1차 시연·테스트용이며, 3차 구독 결제·자동갱신 구현 완료 후 테스트용으로 유지하거나 제거할 예정
    - 슈퍼 관리자만 테스트 회원에게 지급 시점부터 30일 이용권을 지급하며, 결제·자동갱신 없이 지급 관리자와 생성 시각을 기록
    - 체험·유료·해지 예약을 포함한 활성 멤버십이 있으면 지급하지 않으며, 동시 요청에도 한 건만 지급
    - 만료·즉시 종료 이력만 있는 회원은 다시 지급할 수 있고, 지급 이력은 무료체험 가능 여부에 반영
    - 회원별 유형·기간·체험 사용 여부 조회

## 3차

### 유료 회원

- **유료 구독** (담당: 채빈)
    - 월 3,900원
    - 첫 결제 성공을 확인한 뒤에만 유료로 전환
    - 첫 결제일이 월 갱신 기준일
- **무료체험** (담당: 채빈)
    - 이용 이력이 없는 회원은 계정당 1회 7일
    - 휴대전화 중복 불가로 같은 사람의 재가입 체험 반복 차단
    - 시작 시 청구 없음
    - 종료 시 첫 결제가 성공하면 유료 전환
    - 실패하면 일반 회원 전환 후 카드 변경·재구독 안내
- **해지 예약** (담당: 채빈)
    - 체험: 첫 자동 결제 중단, 남은 체험 기간 유지 후 일반 전환
    - 유료: 다음 자동 결제 중단, 결제한 기간 유지 후 만료 시 일반 전환
- **즉시 해지** (담당: 채빈, 환불 처리: 정윤)
    - 유료 멤버십 회원은 이용기간 중 즉시 해지 및 환불을 요청할 수 있습니다.
    - 즉시 해지 요청 API는 멤버십 도메인이 소유합니다.
    - 요청 시 `Idempotency-Key`를 필수로 받고 결제 도메인의 이용료 환불 서비스를 호출합니다.
    - 환불 처리 중에는 멤버십을 `ACTIVE`로 유지합니다.
    - 환불이 `COMPLETED`된 경우에만 멤버십을 즉시 종료합니다.
    - 환불이 명확히 실패하면 멤버십을 `ACTIVE`로 유지합니다.
    - 환불 결과가 불명확하면 `REQUESTED` 상태와 멤버십 `ACTIVE`를 유지하고 웹훅·재조회로 결과를 확인합니다.
    - 결과 불명 건이 나중에 환불 성공으로 확인되면 `즉시 해지 환불 완료 반영`을 통해 멤버십을 종료합니다.
    - 같은 `Idempotency-Key`로 다시 요청하면 새 환불을 만들지 않고 기존 결과를 반환합니다.
    - 같은 이용권에 결과 확인 중인 `REQUESTED` 환불이 있으면 다른 키의 새 요청은 거절합니다.
    - 명확한 실패가 `FAILED`로 확정된 뒤에는 새 `Idempotency-Key`로 다시 요청할 수 있습니다.
- **결제 결과에 따른 전환** (담당: 채빈)
    - 갱신 최종 실패·카드 미등록 만료 결과를 받으면 일반 전환
    - 즉시 해지 환불이 `COMPLETED`된 경우에만 유료 멤버십 종료
    - 같은 요청 안에서 환불 완료가 확인되면 멤버십 도메인이 즉시 종료
    - 결과 불명 후 나중에 성공이 확인되면 결제 도메인의 `즉시 해지 환불 완료 반영` 계약을 통해 종료
    - 환불액이 0원인 경우에도 `COMPLETED` 처리 후 멤버십 종료
- **자동 결제 동의** (담당: 정윤 안내, 채빈 저장)
    - 체험·유료 구독 시작 전 결제 금액·첫 결제일·월 갱신 주기·자동갱신 해지·즉시 해지 방법 안내
    - 동의 금액·동의 문구 버전·동의 일시를 멤버십에 저장
    - 자동 청구 시 멤버십 도메인에 자동청구 대상·동의 여부 확인

### 관리자

- **회원별 멤버십 이력 조회** (담당: 채빈)
    - `SUPER_ADMIN` 전용
    - 회원의 모든 이용권(체험·유료 전환·구독·관리자 지급)과 상태(이용 중·해지 예약·만료·즉시 해지) 조회
